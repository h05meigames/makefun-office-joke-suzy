## The entry

`main.ts` writes a single original one-line joke about office life to
`/output/entry.txt`:

> My boss swore my job was secure — then emailed me the login for the intern replacing me.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network.
